# SQL (5 days)

| Day | Topics |
|---|---|
| 1 | Tables, keys, data types, CREATE, INSERT |
| 2 | SELECT, WHERE, ORDER BY, LIMIT, LIKE, IN, NULL |
| 3 | Aggregates, GROUP BY, HAVING |
| 4 | JOINs, subqueries, UNION |
| 5 | UPDATE, DELETE, transactions, indexes, normalization |

Run with SQLite for a zero-install start: `sqlite3 acme.db < schema.sql`, then `sqlite3 acme.db < queries.sql`.

## Labs
1. Design an e-commerce schema (customers, orders, order_items, products).
2. Answer the 15 business questions in `queries.sql` by writing your own SQL.
