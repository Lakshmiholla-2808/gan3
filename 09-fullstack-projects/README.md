# Full-Stack Projects (8 days)

Teams of 2-3 build one project end to end.

| Project | Backend | Frontend | Database |
|---|---|---|---|
| A. Support Desk (recommended) | Tickets, comments, roles, SLA report | Agent dashboard, customer portal | users, tickets, comments |
| B. Leave Manager | Apply, approve, balances | Manager queue | employees, leaves, holidays |
| C. Inventory and Orders | Stock, order flow | Catalog, cart | products, orders, items |
| D. Expense Tracker | Categories, reports, CSV export | Charts, filters | users, expenses |

## Flow
1. Day 1: requirements, user stories, wireframes, ER diagram
2. Day 2: repo, branching rules, schema and migrations
3. Days 3-4: API endpoints with tests
4. Days 5-6: UI connected to API
5. Day 7: auth, error handling, logging, Docker Compose
6. Day 8: demo, code review, retrospective

## Rubric (100)
Functionality 30, code quality 20, tests 15, database design 10, UI/UX 10, Git hygiene 10, demo and docs 5.

## Starter
`docker-compose.yml` runs Postgres. Add `api` and `web` services as the project grows.
