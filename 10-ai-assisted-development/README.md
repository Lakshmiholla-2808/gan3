# AI-Assisted Development (4 days)

| Day | Topics | Hands-on |
|---|---|---|
| 1 | How coding assistants work, limits, company policy | Compare an AI answer with the docs and find mistakes |
| 2 | Prompting for code | Generate a function and its tests from a good prompt |
| 3 | Workflows: explain, refactor, test, debug, review | Refactor a legacy script and verify with tests |
| 4 | Responsible use: secrets, security, licensing | Spot vulnerabilities in AI-generated code |

Golden rule: AI drafts, you own the result. Read it, run it, test it. Do not accept code you cannot explain.

See `prompt-templates.md` and `review-checklist.md`.
