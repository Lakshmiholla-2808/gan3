# Training flow

| Phase | Weeks | Modules | Goal |
|---|---|---|---|
| A | 1-2 | 01 | Think and code in Python |
| B | 3-4 | 02 | Idiomatic, reusable code |
| C | 5 | 03 | Git, tests, debugging, structure |
| D | 6-7 | 04, 06 | Design and query databases |
| E | 7-8 | 05 | Build and secure REST APIs |
| F | 9-10 | 07, 08 | Build the UI |
| G | 11-12 | 09 | Integrate and deploy |
| H | 13-16 | 10, 11 | Ship an AI-powered product |

## 3-hour session template
1. 10 min recap quiz
2. 30 min concept
3. 40 min live demo
4. 10 min break
5. 60 min lab
6. 20 min review of learner solutions
7. 10 min exit ticket and homework

## Trainer tips
- Live-code and let mistakes happen; debugging is the skill.
- Keep labs inside the Support Desk case.
- Require Git commits from Module 03 onward.
- In Modules 10-11, learners must explain every AI-generated block.

## Shorter tracks
- 2-week bootcamp: 01, light 02, 04, 05
- Backend (8 weeks): 01-06 plus 09
- Frontend (6 weeks): light 01, 07, 08
- AI upskilling for developers (2 weeks): 10, 11
